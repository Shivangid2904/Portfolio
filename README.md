# Shivangi Dubey — Personal Portfolio

A personal portfolio website built with React, Vite, TypeScript, and Tailwind CSS.

## ✦ About

Soft cosmic, feminine, curious — a CS/AI student's little corner of the internet.

Built around ML, data analytics, cloud systems, and a genuine interest in space and astrophysics data.

## 🛠 Tech Stack

- **React** + **Vite** + **TypeScript**
- **Tailwind CSS** (v3)
- **Framer Motion** (animations)
- **Lucide React** (icons)
- **Google Fonts** — Cormorant Garamond + Inter

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
npm run preview
```

## 📁 Structure

```
src/
├── data/          # Project, skill, and personal data (single source of truth)
├── components/
│   ├── layout/    # Navbar, Footer
│   ├── sections/  # Hero, About, Projects, Toolkit, Journey, Exploring, Contact
│   └── ui/        # StarField, SectionHeading, ProjectCard, StatusBadge, SkillPill
└── index.css      # Global styles and design tokens
```
